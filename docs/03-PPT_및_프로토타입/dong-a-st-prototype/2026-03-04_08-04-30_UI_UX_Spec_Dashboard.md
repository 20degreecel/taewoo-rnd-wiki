# UI/UX 화면 정의서 - 통합 대시보드 (Dashboard)

## 📌 1. 화면 개요
- **화면명**: 통합 신약 개발 AI 통합 제어 대시보드
- **경로**: `/` 또는 `/dashboard`
- **목적**: 연구원이 선택한 프로젝트의 현황, 공지사항, 모듈 안내 및 빠른 실행을 지원하는 메인 화면.

## 📐 2. 레이아웃 구조
화면은 좌측 사이드바(Sidebar), 상단 헤더(Header), 중앙 메인 콘텐츠 영역으로 나뉩니다.

### 2.1 사이드바 (Sidebar)
*   **위치**: 화면 좌측 고정 (너비 280px)
*   **항목**:
    *   상단 로고 영역 ("Dong-A ST AI Drug Discovery")
    *   메뉴 리스트: Dashboard, Project Manager, (선택된 프로젝트가 있을 시) Project Modules 리스트
    *   하단: Settings
*   **인터랙션**:
    *   `Inactive`: 현재 선택되지 않은 메뉴 (회색, hover 시 배경색 변경)
    *   `Active`: 현재 활성화된 메뉴 (파란색 하이라이트 배경 및 볼드 처리)
    *   `Disabled`: 프로젝트를 선택해야만 진입할 수 있는 모듈(danovo 등)은 회색으로 딤처리되어 접근 불가 (클릭 시 프로젝트 선택 모달 호출)

### 2.2 상단 헤더 (Header)
*   **항목**:
    *   좌측: 현재 뷰의 Title, Subtitle 표기 (예: "Platform Overview")
    *   우측 상단: 현재 선택된 프로젝트 뱃지 표기, 현재 AI 모델 버전("Model v2.1")
    *   `Ask AI Assistant` 버튼
*   **동작**:
    *   AI Assistant 버튼 클릭 시 우측 하단에서 챗봇 패널 열림

## 🎨 3. 화면 상세 컴포넌트

### 3.1 웰컴 배너 영역
*   **구성**: "안녕하세요, OOO 연구원님!" 인사말과 함께 파란/보라색 그라데이션 원형 배경.
*   **인터랙션**: `AI 어시스턴트와 대화하기` 버튼 클릭 시 챗봇 호출.

### 3.2 공지사항 (Notices) 패널
*   **설명**: 사내 시스템 점검이나 모델 업데이트 알림을 노출하는 위젯.
*   **구성**: 날짜/태그(예: 'Today', 'Yesterday')와 공지 제목, 요약 텍스트로 구성된 리스트 뷰.

### 3.3 모듈 튜토리얼 & 바로가기
*   **설명**: 4개의 핵심 AI 모듈(DABICS, Smart DTI, DANOVO, DAPRE)의 기능 요약 및 튜토리얼 실행 카드.
*   **인터랙션**: 각 카드를 클릭하면 해당 모듈의 `TutorialModal`이 중앙 팝업으로 나타납니다.

### 3.4 헬프데스크 (Help Desk) 패널
*   **설명**: 사용자 문의 및 기술 지원 현황 리스트.
*   **상태 표시**: '처리중' (노란색), '완료' (초록색) 등의 진행 상태 뱃지 포함.

## 📝 4. 주요 모달 / 패널 (Overlay)

### 4.1 AI Assistant Chat
*   **위치**: 화면 우측 하단 고정 팝업.
*   **기능**: 사용자의 자연어 입력을 받아 Gemini API(또는 내부 LLM)로 프롬프트를 전송하고 응답받는 챗봇 모달.

### 4.2 튜토리얼 모달 (TutorialModal)
*   **동작**: 위 "모듈 튜토리얼" 또는 사이드바에서 도움말 가이드 아이콘을 눌렀을 때 등장.
*   **구성**: 해당 모듈이 어떤 프로세스(Step 1~4)로 진행되는지 순서대로 설명.
*   **종료**: `닫기` 버튼 또는 `이 모듈로 이동하기` 버튼 클릭 시 라우팅 변경 및 닫힘.
