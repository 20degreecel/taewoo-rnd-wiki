# UI/UX 화면 정의서 - DANOVO (Molecule Generation)

## 📌 1. 화면 개요
- **화면명**: DANOVO (Generative Design)
- **경로**: `/danovo`
- **목적**: 딥러닝 기반의 De Novo 디자인, Scaffold Hopping, 강화학습(RL)을 통해 신규 화합물 구조를 생성하고 분석하는 파이프라인.

## 📐 2. 레이아웃 구조
좌측 파이프라인 제어 패널과 우측 상태 표시/결과 분석 패널로 나뉘는 2-Column 구조.

### 2.1 좌측 패널 (제어 및 워크스페이스)
*   **모드 선택 탭 (Mode Selection)**:
    *   `De Novo`: 씨드(Seed) 구조를 기반으로 Fine-tuning 하여 새로운 유도체를 무작위 생성.
    *   `Scaffold`: 코어 스켈레톤(Scaffold)을 고정하고 R-group에 치환기를 붙여 생성(Morphing).
    *   `RL`: 특정 물성(예: QED, Docking Score)을 보상 함수로 두고 정책(Policy) 모델을 강화학습.
*   **워크스페이스 (Workspace)**:
    *   현재 프로젝트에 업로드된 Input(`.smi`) 파일과 생성된 Result 파일 목록 트리 뷰.
*   **파이프라인 스텝 제어부**:
    *   **Step 1: Input & Model Config**: 모드에 따른 입력 데이터(씨드 구조, Scaffold, FT 파라미터 등) 설정.
    *   **Step 2: Smart Gatekeeper**: 생성된 물질의 유효성을 1차 검증(Lipinski 규칙 등)하는 필터링 조건.
    *   **Step 3: Validation**: 고정밀 시뮬레이션(Glide 등) 검증 진행 상태 로더.

### 2.2 우측 패널 (메인 뷰 / 터미널)
*   **A. 파이프라인 모드 (Generation Running)**:
    *   하단 터미널: 백엔드 서버에서 실행 중인 python 스크립트 실행 로그 스크롤 뷰. (실시간 진행 상황 모니터링)
*   **B. 결과 분석 모드 (Result Viewer)**:
    *   파이프라인 완료 또는 워크스페이스에서 `result` 파일 클릭 시 전환.
    *   **Card View**: 생성된 분자의 2D 구조식 뷰어(RDKit) 및 좌우 스와이프 기능. 하단에는 분자량(MW), LogP 등의 물성치 위젯 제공.
    *   **List View**: 표 형태로 식별자, 물성치 등을 리스트업.

## 🎨 3. 화면 상세 컴포넌트

### 3.1 Scaffold Select Viewer (Smart Scaffold Viewer)
*   **설명**: Scaffold 모드 시, 사용자가 업로드한 코어 구조체에서 치환이 일어날 위치(Vector)를 마우스 클릭으로 선택하는 양방향 웹 컴포넌트.
*   **인터랙션**: SVG 구조식의 `R1, R2` 등 부착 지점을 클릭하면 파란색 점선 원으로 활성화 상태 표시.

### 3.2 Fine-tuning Parameters Input
*   **설명**: De Novo 모드 시 학습률(Learning Rate), 에포크(Epochs), 샘플 사이즈(Sample Size)를 조절할 수 있는 슬라이더 및 셀렉트 박스.

### 3.3 Hit Selection 저장 기능
*   **설명**: Result Viewer에서 마음에 드는 구조체에 `Select to Keep` (별 모양) 버튼을 눌러 담아둔 후, 우측 하단의 플로팅 바에서 일괄 저장(Save Selected as New File)하는 기능.
